#🐟 Diary Koi
Diary Koi es una plataforma online para crear, escribir y organizar diarios digitales de forma sencilla.

#✨ Características principales
-Crear y editar entradas de diario en línea.
-Organizar tus notas
-Interfaz simple y enfocada en la escritura.
#🛠️ Tecnologías utilizadas
-Frontend: [Ej. React, HTML/CSS, Tailwind]
-Backend: [Ej. Node.js, Express]
-Base de datos: [Mongo DB]
